# Передай изображение

Загрузка JPG, PNG, GIF или WebP до 50 МиБ с ссылкой на пять минут. Срок начинается после загрузки; по истечении файлы перестают отдаваться сервером. Один IP может иметь одну активную ссылку; при общем IP ограничение действует для всех пользователей этого адреса.

Данные и файлы лежат вне корня сайта в каталоге `photo-share-data` рядом с `public`. Путь можно переопределить переменной `TEMP_IMAGE_STORAGE`. Каталог должен быть доступен пользователю PHP. IP-адрес сохраняется только в виде HMAC с локальным ключом; постоянная база данных не нужна.

Для физического удаления файлов после истечения срока запускайте `cleanup.php` каждую минуту из планировщика от пользователя PHP. Обработчик отказывает в доступе по истёкшей ссылке независимо от планировщика; если он остановлен, файлы могут оставаться на диске до возобновления очистки. Поддержка размеров в PHP-FPM зависит от `upload_max_filesize` и `post_max_size`; для обычной конфигурации FPM приложен `.user.ini`.

При разработке использован разбор размера PHP из проекта [Fileshare](https://github.com/svandragt/fileshare); текст лицензии — в `LICENSE-fileshare.txt`.

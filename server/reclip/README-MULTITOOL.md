# ReClip в Мультитуле

Работающий Python/Flask-сервис расположен на VPS в `/opt/reclip`, за nginx-маршрутом `/reclip/`. Публичные исходники здесь соответствуют сервису; папка `downloads`, окружение Python, журналы и пользовательские файлы в Git не входят.

Изменения 16.11.2026: общее избранное, навигация «Поиск и загрузка», список основных хостингов с поиском, понятное объяснение серверной обработки, подключение дополнения Threads с проверкой точного идентификатора публикации.

Ограничение yt-dlp: `--max-filesize 1G`. Перед загрузкой интерфейс показывает приблизительный размер результата по длительности и качеству. После ответа `/api/file` временный результат удаляется; таймер сохраняется как резервная очистка оставшихся временных файлов. Для установки используются действующее окружение и существующий сервис, исходники заменяются с резервной копией.

Основа: https://github.com/averygan/reclip (MIT). Дополнение: https://github.com/tribixbite/yt-dlp-threads (Unlicense); точная версия в `plugins/threads/SOURCE.json`. Дополнение обрабатывает публичные видео, включая видеокарусели. Безопасная локальная правка запрещает подменять нераспознанную короткую ссылку первым рекомендованным видео.

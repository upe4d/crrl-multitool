# Русский интерфейс игр

В `mini/*.ru.json` находятся полные строки и шаблоны для 106 Mini Games. Парные `.ru.js` загружаются браузером без сборщика. После правки JSON выполните `node scripts/build-game-locales.cjs` из корня репозитория.

Переводчик `../locale-core.js` сопоставляет фразу целиком и переносит значения `{v0}`, `{v1}` и других подстановок. Он не склеивает предложения из переводов отдельных китайских слов. Переменные в исходниках, данные сохранений и правила игр не меняются. Адаптер переводит видимые DOM-строки, canvas-текст и сообщения стандартных диалогов.

`mini-guides.ru.txt` содержит первые действия, условия прохождения и советы для каждой Mini Game. `fair-controls.ru.json` — конкретное управление для 64 игр Night Fair. Готовая общая справка для 173 игр находится в `../guides.ru.json` и открывается кнопкой «Как играть» на панели Мультитула.

Русские инструкции отредактированы по игровой механике, включая длинные условия заданий и динамические результаты. Переведены интерфейс и пояснения. Учебные иероглифы, пиньинь, английские ответы в кроссвордах и технические коды сохранений сохраняют нужную игре запись. Переключатель «Оригинал» позволяет свериться с авторским вариантом.

Для проверки: `node tests/game-locales.test.cjs` и `node tests/game-rules.test.cjs`. Первая команда проверяет все 16 770 словарных строк и шаблонов и контрольные суммы оригинального HTML без подключений адаптера. Проверки запуска и поведения в браузере описаны в `../../docs/game-localization-20261116.md`.

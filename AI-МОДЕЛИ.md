# ИИ-модели и PWA

Модели, голоса и языковые файлы для встроенных инструментов размещаются в каталоге `models` в корне сайта. Для переноса их нужно распаковать из отдельных архивов рядом с `index.html` и `sw.js`. Необходимые файлы запрашиваются с того же сайта при использовании инструмента, а вычисления выполняются браузером на устройстве посетителя.

Первое использование может потребовать значительной загрузки. Браузер может сохранить загруженные файлы и повторно использовать их, но вправе очистить своё хранилище; установка PWA не гарантирует постоянного хранения или полноценной работы без интернета. Сервисный работник не добавляет модели и данные заметок в свой кэш.

Список источников, контрольных сумм и версий находится в `models/manifest.json`, условия использования моделей и отдельных голосов — в `models/ИСТОЧНИКИ-И-ЛИЦЕНЗИИ.md`. У некоторых голосов указаны некоммерческие условия; для части ресурсов условия отдельно не подтверждены. Лицензия кода IMG.LY — AGPL-3.0, условия распространения файлов его модели требуют отдельного выяснения.

Для ИИ-черновиков новостей используется отдельная интеграция Ollama. Браузерные модели не заменяют этот сервер; обычный PHP-хостинг без фоновых процессов не запускает Ollama. Сетевые функции, включая новости и сервер заметок, требуют подключения.

Источники: [Transformers.js: настройка источника моделей](https://huggingface.co/docs/transformers.js/en/custom_usage), [MDN: хранение и очистка данных браузера](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria), [IMG.LY: лицензия кода](https://github.com/imgly/background-removal-js#license).

# Текст и данные

Небольшой автономный набор инструментов, самостоятельно реализованных по образцу общего назначения BrowseryTools (https://github.com/aghyad97/browserytools). Счётчик, регистр, JSON, Base64 UTF-8, кодирование URL, SHA-256, генерация паролей и UUID выполняются в браузере. Нужен HTTPS или localhost для функций Web Crypto. PHP и Python для этого каталога не нужны — достаточно разместить три файла под одним URL.

Это отдельная реализация восьми функций, а не перенос исходного BrowseryTools целиком. Исходный репозиторий находится рядом в browserytools-source и распространяется по лицензии AGPL-3.0-only. Для исходного проекта и его модификаций необходимо учитывать условия лицензии; для работы полного Next.js-приложения нужна совместимая серверная среда или отдельная подтверждённая статическая сборка.

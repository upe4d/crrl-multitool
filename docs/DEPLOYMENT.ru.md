# Размещение Мультитула

[Обзор проекта](../README.md) · [English](DEPLOYMENT.en.md)

Репозиторий содержит готовые браузерные сборки и PHP-файлы. Для обычного размещения устанавливать Node.js и собирать сторонние приложения не требуется. Дополнительные серверные службы подключаются отдельно.

## Базовая установка

1. Скачайте репозиторий или выполните `git clone https://github.com/upe4d/crrl-multitool.git`.
2. Разместите содержимое в корне отдельного домена с HTTPS. Пути вида `/reference/` и `/tancn/` рассчитаны на корень, а не подпапку.
3. Выберите PHP 8.1 или новее с расширениями `mbstring`, `dom`, `json`, `openssl`. Для PHP-запросов к источникам нужен исходящий HTTPS, `allow_url_fopen` и действующее хранилище сертификатов.
4. Настройте PrivateBin и каталоги хранения из таблицы ниже. На обычном хостинге задайте переменные окружения доступными средствами панели или измените соответствующие значения по умолчанию в PHP-файлах.
5. Проверьте HTTP-заголовки и открытие каждого нужного модуля. Наличие статической страницы не подтверждает готовность её серверных функций.

## Данные экземпляра

| Модуль | Настройка | Размещение |
| --- | --- | --- |
| Избранное и профили | `MULTITOOL_ACCOUNTS_DIR`, [api/favorites/index.php](../api/favorites/index.php) | По умолчанию `/var/lib/multitool-accounts`. Отдельная папка вне публичного каталога, доступная PHP для записи. |
| Счётчик переходов | `MULTITOOL_STATS_DIR`, [directions/stats.php](../directions/stats.php) | По умолчанию `/var/lib/multitool-stats`. Отдельная папка вне публичного каталога, доступная PHP для записи. |
| Реестр компонентов TANCN | `TANCN_REGISTRY_DIR`, [tancn/registry.php](../tancn/registry.php) | По умолчанию `/var/lib/multitool-tancn/registry`. Отдельная папка вне публичного каталога, доступная PHP для записи. |
| Заметки PrivateBin | `n/cfg/conf.php`, `n/data/` | Конфигурация и данные экземпляра исключены из Git. Создайте конфигурацию для своего размещения по [документации PrivateBin](https://github.com/PrivateBin/PrivateBin/wiki/Configuration). |

Убедитесь, что веб-сервер запрещает чтение `n/cfg/` и `n/data/`. Правила `.htaccess` рассчитаны на Apache с разрешёнными переопределениями. Nginx сам по себе их не читает: запрет должен быть в конфигурации сайта. Не выдавайте публичный доступ к папкам данных вместо исправления прав PHP.

Для резервной копии работающего экземпляра нужны и файлы приложения, и его отдельные каталоги данных. Репозиторий GitHub не содержит пользовательские заметки, профили или ключи.

## Домен и запуск кода

- В `tancn/registry.php` проверка Origin и выдаваемая CLI-ссылка используют `https://tools.crrl.ru`. Перед использованием реестра на своём домене замените обе привязки на свой HTTPS-адрес. Явно опубликованные компоненты доступны по ссылке в течение 24 часов.
- Среде исполнения требуется CORS для публичных статических ресурсов `/code-playground/`: `Access-Control-Allow-Origin: *`. Это правило должно действовать только на каталог публичных файлов, без распространения на PHP API и пользовательские данные.
- Сохраните типы файлов JavaScript, WebAssembly и JSON. Если хостинг блокирует загрузку runtime или Worker, редактор откроется, но исполнение кода завершится ошибкой.
- Некоторые среды, модели и библиотеки загружаются по сети при первом использовании. Установленная PWA не делает все инструменты автономными.

## Дополнительные службы

| Возможность | Что потребуется |
| --- | --- |
| ReClip, поиск организаций | Отдельные серверные приложения и маршруты. Они не запускаются автоматически от копирования PHP-пакета. |
| Серверная конвертация документов и медиа | Настроенные серверные процессы и соответствующие программы, например LibreOffice или FFmpeg. Браузерные операции имеют собственные ограничения. |
| ИИ-черновики и генерация TANCN | Отдельно настроенный провайдер или локальная модель; API-ключи не публикуются в клиентском коде. |
| DashBeam | Доступ к сетевым реле; веб-клиент не равнозначен прямому соединению настольного клиента. |

## Проверка после размещения

Откройте главную страницу, поиск, избранное, шпаргалку и TANCN. Выполните короткий пример кода, сохраните тестовую заметку, проверьте чтение созданной ссылки и откройте сайт с телефона. Отдельно проверьте запрет веб-доступа к конфигурации и данным PrivateBin. Проверка опубликованного сайта CRRL не заменяет проверку новой установки.

Сохраняйте лицензии и архивы исходников из [списка компонентов](THIRD_PARTY.md). Дополнительные ограничения пакета перечислены в [памятке установки](../README-ПЕРЕД-УСТАНОВКОЙ.txt).

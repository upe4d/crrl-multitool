ПРОФИ / ВРЕМЕННЫЙ ПОЧТОВЫЙ ЯЩИК

TempMail

Получите одноразовый адрес для тестирования писем и разовых регистраций, чтобы не указывать основную почту.

Как пользоваться

  1. Запустите TempMail и дождитесь появления адреса.
  2. Скопируйте адрес и укажите его там, где ждёте письмо.
  3. Нажмите Refresh — «Обновить», затем откройте входящее письмо.

New Address — новый адрес. Auto — автообновление. Inbox — входящие. Copy code — скопировать код из письма.

Где хранится почта

Адрес и письма обслуживает Guerrilla Mail. По описанию TempMail письма хранятся около 60 минут. Доступ к временному ящику не подходит для важных писем или восстановления основного аккаунта.

Мы открываем официальное приложение, не размещая его копию. Язык самого TempMail — английский или турецкий.

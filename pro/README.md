# Профессиональные инструменты

Проверка DNS выполняется в браузере через общедоступные JSON API Google Public DNS и Cloudflare. Сервисы используют anycast; это не проверка из всех регионов мира. Запрос пользователя отправляется выбранным сервисам. При недоступности сети или блокировке браузером показывается ошибка конкретного сервиса.

## В планах: MinerU

Подключить разбор PDF, сканов и таблиц после подготовки отдельного вычислительного сервера. До интеграции проверить реальные потребности в памяти, очереди и очистку загруженных файлов, провести испытания на документах и предусмотреть ограничение нагрузки. Модели и сервис MinerU в этом каталоге отсутствуют; отправки файлов сейчас нет.

Документация: https://github.com/opendatalab/MinerU
